# 📖 Руководство пользователя FluxProxy

**FluxProxy** — это удобная настольная программа для просмотра, проверки и отладки сетевых запросов на компьютере и мобильных устройствах.

Если сайт выдает непонятную ошибку, мобильное приложение долго грузит экран, нужно посмотреть, какие данные уходят на сервер, или проверить работу интерфейса еще до того, как готов бэкенд — FluxProxy покажет каждый запрос изнутри и позволит менять данные прямо на лету.

> [!TIP]
> Для программируемой модификации и мокирования трафика на языке Python 3 (`on_request` / `on_response`) см. отдельное [**Руководство по Python Scripting Engine (`PYTHON_SCRIPTING_GUIDE.md`)**](PYTHON_SCRIPTING_GUIDE.md), а для генерации скриптов через нейросети — [**инструкцию для AI-агентов (`PYTHON_SCRIPTING_AI_GUIDE.md`)**](PYTHON_SCRIPTING_AI_GUIDE.md).

## 1. Зачем нужен FluxProxy

В отличие от встроенной вкладки *Network* в браузере, FluxProxy умеет гораздо больше:
- **Видит трафик любых программ**, а не только одной вкладки браузера: настольных приложений, локальных серверов, скриптов и подключенных по Wi-Fi смартфонов.
- **Показывает, какая именно программа отправила запрос** (например, `chrome.exe`, `node.exe` или телефон в вашей сети).
- **Позволяет менять запросы и ответы без правки кода**: можно поставить соединение на паузу, вписать другие данные или подставить ошибку `500`, чтобы проверить, как отреагирует приложение.
- **Умеет сохранять и открывать полные записи трафика** (`.har` и `.saz`), чтобы приложить их к задаче для разработчика.

## 2. Быстрый старт за 3 минуты

### Шаг 0. Скачайте и установите программу
Для Windows доступны готовые официальные установщики из [**GitHub Releases v0.7.1**](https://github.com/maq3000/flux-proxy/releases/tag/v0.7.1):
- [📥 **FluxProxy Setup (.exe)**](https://github.com/maq3000/flux-proxy/releases/download/v0.7.1/FluxProxy_0.7.1_x64-setup.exe) — стандартный установщик для домашнего и рабочего использования (автоматически создает ярлыки и деинсталлятор).
- [📥 **FluxProxy Package (.msi)**](https://github.com/maq3000/flux-proxy/releases/download/v0.7.1/FluxProxy_0.7.1_x64_en-US.msi) — MSI-пакет для корпоративного развертывания (GPO / Active Directory).

Запустите скачанный файл и завершите простую установку.

### Шаг 1. Включите перехват трафика
При запуске FluxProxy сразу готов к работе на локальном порту `8888`.

1. Убедитесь, что кнопка захвата в левом верхнем углу горит зеленым (показывает `127.0.0.1:8888`). Включать и ставить захват на паузу удобно клавишей **`F12`**.
2. Чтобы браузеры и программы на вашем компьютере автоматически пустили свой трафик через FluxProxy, включите **системный прокси**:
   - Нажмите на индикатор **`SysProxy`** в верхней или нижней полосе окна (или выберите **File → Act as OS System Proxy**).
   - Когда вы закроете FluxProxy или поставите захват на паузу (`F12`), программа **сама вернет прежние сетевые настройки** вашей системы — вручную ничего выключать не придется. При нажатии `F12` уже открытые загрузки и WebSocket-соединения аккуратно завершаются (Graceful Drain до `30 с`) без мгновенного обрыва активной вкладки, а при закрытии приложения или сужении сетевого доступа прерываются немедленно.

### Шаг 2. Установите сертификат для защищенных сайтов (HTTPS)
Почти все современные сайты работают по защищенному протоколу HTTPS. Чтобы браузер доверял FluxProxy и не показывал экран *«Подключение не защищено»*, нужно **один раз** установить локальный сертификат программы:

1. В верхнем меню откройте **Tools → Root CA** (или выберите *Root CA* в командной палитре `Ctrl+K`).
2. Нажмите зеленую кнопку **Trust Root CA in OS Store** и подтвердите системный запрос. *(На Linux поддерживаются стандартные хранилища Debian/Ubuntu, Fedora/RHEL/openSUSE и Arch Linux; если системный диалог macOS `security` или Linux `pkexec` отменён или не завершился за `60 с`, окно вернётся в рабочее состояние и покажет готовую CLI-команду для ручной установки в терминале с кнопкой **Копировать команду**.)*
3. Статус в окне сменится на **«Установлен (доверен ОС)»**. После этого Chrome, Edge, Safari и системные программы сразу начнут открывать HTTPS-сайты без ошибок.

> [!TIP]
> **Пользуетесь Mozilla Firefox?** Этот браузер не использует системное хранилище сертификатов. В том же окне нажмите кнопку копирования рядом с путем к файлу `.cer`, затем в Firefox откройте *Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов → Центры сертификации → Импортировать…*, выберите этот файл и отметьте доверие для веб-сайтов.

> [!NOTE]
> Если после завершения работы вы захотите полностью удалить сертификат программы из системы, откройте это же окно и нажмите **«Удалить сертификат из доверенных ОС»**.

### Шаг 3. Оставьте на экране только нужный сайт
Как только вы включите системный прокси, в таблицу начнут попадать десятки фоновых запросов от операционной системы, мессенджеров и вкладок браузера. Чтобы сразу сфокусироваться на деле:
- Нажмите **`Ctrl+F`** и начните вводить адрес нужного сайта (например, `my-shop.ru` или `/api/login`) — всё лишнее мгновенно скроется.
- Либо нажмите кнопку **`Filter`** справа от поиска и выберите готовый набор **«Только API бэкенда»**.

## 3. Как устроено окно программы и настройка под себя

Окно FluxProxy построено по понятной 3-уровневой архитектуре (7 неблокирующих вкладок, полноэкранные инструменты и компактные диалоги) и разделено на следующие области:

- **Верхнее меню (`File`, `Edit`, `Rules`, `View`, `Tools`, `Help`)** — полный доступ ко всем функциям, переключению видов (`Grid` / `Waterfall` / `Traffic Statistics`), сохранению архивов и настройкам.
- **Панель инструментов** — главные кнопки под рукой: пауза захвата (`F12`), очистка списка, лимит сессий (`Keep`), строка быстрого поиска, категории трафика, всегда видимый селектор **`Throttle`** + кнопка **`Routing`**, режим HTTPS MITM и точки останова. У сложных кнопок есть контекстные подсказки при наведении.
- **Левая боковая панель (`Sidebar`)** — мгновенное переключение между **7 неблокирующими рабочими вкладками** (при переходе между вкладками открытые черновики, пары сравнения и введённые данные сохраняются) и кнопкой **`Settings` (`Ctrl+,`)** внизу:
  - **Traffic (`Alt+1`)** — список всех перехваченных запросов (`Grid` ↔ `Waterfall Timeline`) и сводная статистика (`Statistics`);
  - **Composer (`Alt+2` или клавиша `E` на выбранной строке)** — ручная сборка, редактирование и повторная отправка своих запросов;
  - **AutoResponder (`Alt+3`)** — правила автоматической подмены ответов и задержек;
  - **Breakpoints (`Alt+6`)** — интерактивная пауза и правка запросов/ответов на лету;
  - **Scripts (`Alt+5`)** — программируемая обработка запросов и ответов на Python 3 (подробнее см. [PYTHON_SCRIPTING_GUIDE.md](PYTHON_SCRIPTING_GUIDE.md));
  - **Session Diff (`Ctrl+D`)** — построчное сравнение двух сессий;
  - **TextWizard (`Ctrl+E`)** — декодер JWT, Base64, URL, сжатия, Hex и Timestamp.
  *(Быстрый переход в расширенные фильтры доступен по **`Alt+4`** — открывает `Settings → Filters`.)*
- **Заголовок активного раздела (`SectionHeader`)** — лаконичное название текущей вкладки или экрана с кнопкой справки **`ⓘ`**, раскрывающей краткое описание возможностей и ключевых шорткатов раздела.
- **Таблица запросов / Waterfall Timeline** — живой поток всех перехваченных обращений к сети.
- **Инспектор (снизу или справа)** — подробное содержимое выбранного запроса и ответа сервера. Инспектор можно свернуть (кнопкой или перетащив разделитель до края) — на его месте останется компактная **панель возврата свёрнутого инспектора** с названием выбранной сессии, кнопкой быстрого перехода в `Statistics` и переключением позиции (`Bottom` / `Right`).
- **Строка состояния (внизу)** — подсказки о текущем режиме прокси, подключении телефонов, активных правилах маршрутизации и расходе памяти/SQLite.

### Как сделать интерфейс удобнее под свой экран:
- **Работаете на небольшом экране ноутбука?** Нажмите **`Ctrl+Shift+T`** (или откройте **View → Slim / Compact Toolbar**), чтобы переключить однострочную компактную панель, а левую панель сверните клавишей **`Ctrl+B`**. В меню **View → Customize Toolbar** можно отключить группы кнопок, которыми вы не пользуетесь.
- **Удобнее смотреть детали справа, а не снизу?** На широкоформатных мониторах выберите **View → Dock Inspector on Right** (или переключите расположение прямо из контекстного меню разделителя / свёрнутой панели инспектора). Все пропорции сплит-панелей и выбранная ориентация Инспектора **автоматически сохраняются** между перезапусками; двойной клик по границе между панелями сбрасывает их к сбалансированному размеру, а пункт **View → Reset Panel Layout to Default** возвращает стандартную раскладку.
- **Темы оформления и настройка палитры (8 пресетов):** откройте **Settings (`Ctrl+,`) → *Appearance & Layout*** (или **View → Appearance & Layout**, либо через **`Ctrl+K`**) — здесь доступна галерея из **8 встроенных тем** (*Flux Dark*, *Flux Light*, *Dracula*, *Tokyo Night*, *Nord*, *Fiddler Classic*, *GitHub Dark*, *Monokai Pro*) и раскрываемый редактор палитры для точной подстройки фонов, текста, акцентов и цветов статусов `2xx/3xx/4xx/5xx/WS` с автоматической синхронизацией редактора **Monaco**.
- **Единое контекстное меню (правая кнопка мыши):** правый клик работает осознанно во всех частях программы — по строкам, шапке и пустой области таблицы (`Traffic` и `Waterfall`), по URL-бару, заголовкам, cookies, вкладкам `WS`/`SSE`/`Hex`/`Image`/`Statistics` и выделенному тексту в Инспекторе, в `Composer`, `AutoResponder`, `Breakpoints`, консоли `Scripts`, `Session Diff`, `TextWizard`, на тулбаре, сайдбаре, разделителях панелей и в нижней строке состояния. При этом внутри редактора **Monaco** сохраняется его штатное меню, а в текстовых полях — привычные операции `Cut / Copy / Paste / Select All`.
- **Командная палитра 2.0 (`Ctrl+K` / `Cmd+K`):** позволяет найти и выполнить любое действие по названию, фильтровать команды по категориям клавишей **`Tab`**, видеть текущий статус функций на бейджах и в один клик запускать быстрые команды QuickExec (`bpu /api`, `bpafter /graphql`, `jwt`, `doctor`, `mtls`, `waterfall`, `stats`).
- **Настройка и сортировка колонок таблицы:**
  - Нажмите на заголовок любой колонки, чтобы отсортировать список (`▲` по возрастанию → `▼` по убыванию → повторный клик сбрасывает сортировку).
  - Потяните границу заголовка колонки мышкой, чтобы изменить ширину, или **дважды кликните** по границе для автоподбора ширины под содержимое.
  - Нажмите **правой кнопкой мыши по шапке таблицы**, чтобы отсортировать колонку, выполнить **Auto-fit** для выбранной или сразу всех видимых колонок (**Auto-fit All Visible Columns**), скрыть или включить дополнительные столбцы (например, скрытые по умолчанию **`TTFB`** и **`Server IP`**) или вернуть ширину по умолчанию (**Reset**).

## 4. Работа со списком запросов

Каждая строка в таблице — это один сетевой запрос и ответ на него.

### На что обращать внимание в строке:
- **Цвет статуса ответа:**
  - 🟢 **2xx (200, 201, 204)** — запрос прошел успешно;
  - 🔵 **3xx (301, 302, 304)** — перенаправление или ответ из кэша;
  - 🟠 **4xx (400, 401, 403, 404)** — ошибка в запросе или нет доступа;
  - 🔴 **5xx (500, 502, 503)** — ошибка на стороне сервера;
  - **`...` (`Pending`)** — запрос только что отправлен в сеть и прямо сейчас ожидает ответа от сервера (двухфазный захват): вы сразу можете открыть строку и посмотреть исходящие заголовки и тело в Инспекторе, а при получении ответа строка обновится на месте;
  - **`WAIT`** — запрос прямо сейчас стоит на паузе и ждет вашего решения.
- **Метки рядом с адресом:**
  - **`MOCK`** — ответ выдан не реальным сервером, а вашим правилом подмены в AutoResponder или Python-скриптом;
  - **`TUNNEL`** — трафик прошёл через прямой TCP-туннель (TLS Bypass / Targeted Allowlist) без MITM-расшифровки;
  - **`BP:REQ` / `BP:RES` / `BP-MOD`** — запрос пойман точкой останова или изменен вами вручную;
  - **`HDR`** — заголовки были автоматически изменены правилом фильтрации или Python-скриптом;
  - **`REMAP`** — запрос перенаправлен на локальный или тестовый адрес через виртуальный DNS (**HOSTS Remapping**, `Ctrl+Shift+H`);
  - **`💬`** — к запросу добавлена ваша текстовая заметка.
- **Подсветка медленных запросов и детализация времени (колонки `Time`, `TTFB`, `Server IP`):** если сервер отвечает слишком долго (по умолчанию дольше `500 мс` — оранжевый огонек, дольше `1500 мс` — красный), программа сразу подсветит такие узкие места. При наведении курсора на ячейку **Time** появляется всплывающая подсказка с разбивкой по фазам (`DNS`, `TCP`, `TLS`, `TTFB`, `Download`), а через контекстное меню шапки таблицы можно включить дополнительные сортируемые колонки **`TTFB`** и **`Server IP`** (при активном *Upstream Proxy* в ней отображается `via <ip>:<port>`). Чтобы мгновенно найти самые долгие или крупные запросы, кликните по заголовку колонки **Time**, **TTFB** или **Size** для сортировки списка.
- **Быстрое выделение всех видимых запросов:** нажмите **`Ctrl+A`** (`Cmd+A` на macOS) или выберите **Edit → Select All Sessions**, чтобы выделить сразу все отфильтрованные строки в таблице для массового экспорта, удаления или пометки (`Escape` сбрасывает множественное выделение).
- **Клик по источнику (колонка Process):** нажмите прямо на имя программы (например, `postman.exe`) или на зеленый значок смартфона 📱 с IP-адресом — таблица тут же отфильтруется и покажет трафик только от этого устройства или приложения.

### Многофазный Waterfall Timeline и сводная статистика (`Traffic Statistics`)
В правом верхнем углу заголовка вкладки **Traffic** расположены переключатель **`Grid | Waterfall`** и кнопка **`Statistics`**:
- **Waterfall Timeline (`Waterfall`):** превращает список запросов в виртуализированную каскадную временную диаграмму (плавно работает на 10 000+ сессий). Каждая полоса строится относительно начала выборки и разбивается цветом по реальным сетевым фазам (**`DNS`**, **`TCP`**, **`TLS`**, **`Wait (TTFB)`**, **`Download`**; для импортированных сессий без фаз используется сплошная полоса по статусу). Доступно управление масштабом (**`Zoom In`**, **`Zoom Out`**, **`Fit All`**), подробная всплывающая подсказка по фазам при наведении, правый клик по строкам и синхронизация выбранной строки с **Session Inspector**. Переключить режим можно также через **View → Traffic View: Waterfall Timeline** или командную палитру **`Ctrl+K` → `waterfall`**.
- **Сводная статистика (`Statistics`):** открывает полноформатный аналитический отчёт по **всей отфильтрованной выборке** (`Filtered Sample`) или **выделенным строкам** (`Selected Sessions`): распределение статусов `2xx / 3xx / 4xx / 5xx / Pending`, суммарный трафик (`Wire` vs `Decoded`), `Avg / Median / P95` длительности и `TTFB`, разбивка по типам контента (`MIME`) и хостам (клик по хосту сразу фильтрует таблицу), а также **топ-5 самых медленных** и **топ-5 самых крупных URL** (клик переходит к нужной сессии). Кнопка **Copy Markdown Report** копирует готовый Markdown-отчёт в буфер обмена для баг-трекера или отчёта о производительности. Также вызывается через **View → Traffic Statistics Summary…**, **Tools → Traffic Statistics Report…**, правый клик в таблице или **`Ctrl+K` → `stats`**.

### Быстрые действия с запросом (правый клик мышью по строке):
- **Повторить запрос (`R` или `Ctrl+R`)** — заново отправить точно такой же запрос на сервер (с применением активных Python-скриптов) и посмотреть свежий ответ.
- **Открыть в Composer (`E`)** — мгновенно перенести запрос во вкладку **Composer**, чтобы подправить параметры и отправить вручную.
- **Сгенерировать клиентский код (`Code Generator`)** — получить готовый сниппет для JavaScript (`fetch`/`axios`), Python (`requests`/`httpx`), Go, Rust или cURL.
- **Экспорт OpenAPI (`OpenAPI Export`)** — сформировать документацию OpenAPI 3.0.3 (YAML/JSON) по выбранным строкам.
- **Сравнить в Session Diff (`Ctrl+D`)** — сравнить с другим запросом.
- **Скопировать ссылку (`Ctrl+C`)**, заголовки или **готовую команду `Copy as cURL`** (ее можно вставить в терминал или Postman, или переслать коллеге).
- **Пометить цветом и добавить заметку (`M`)** — выделите важный запрос цветом и подпишите комментарий (снять пометку — клавиша **`U`**).
- **Создать правило AutoResponder** или **точку останова (`bpu` / `bpafter`)** — в один клик настроить подмену ответа или перехват по адресу.
- **Разрешить IP в LAN Allowlist (`<IP>`)** *(для строк от внешних устройств)* — в один клик добавить IP-адрес смартфона или планшета в белый список **`LAN Client Allowlist`**.
- **Сохранить в файл** — выгрузить выбранные строки в архив `.har` / `.saz` или скачать само тело ответа (например, картинку или JSON).

## 5. Детальный разбор запроса и ответа (Инспектор)

Кликните по любой строке в таблице (или нажмите **`Enter` / `Пробел`**), чтобы открыть подробности. Одна половина инспектора показывает **что отправило ваше устройство (Request)**, а вторая — **что ответил сервер (Response)**. Вкладки активной половины удобно переключать сочетаниями **`Ctrl+1` … `Ctrl+6`**: `1` — *Headers*, `2` — *JSON* (или *Raw*, если тело не JSON), `3` — *Cookies* / *Params*, `4` — *Auth*, `5` — *Raw*, `6` — *Hex*.

### Основные вкладки на каждый день:
- **Headers** — все служебные заголовки с удобным копированием в один клик.
- **Params** — параметры из адресной строки (после знака `?`), аккуратно разложенные в таблицу и очищенные от непонятных `%20`.
- **Cookies** — отправленные и полученные куки, включая отметки их защищенности (`HttpOnly`, `Secure`, `SameSite`).
- **JSON / XML** — красиво отформатированный текст данных с подсветкой и поиском (`Ctrl+F` внутри редактора).
- **Image** — предпросмотр картинок, иконок и графики с указанием их размера и разрешения.
- **Raw** — исходный вид сообщения ровно так, как оно передавалось по сети.

### Специальные вкладки, когда нужно копнуть глубже:
- **Auth (Авторизация)** — сама находит токены доступа и логины/пароли в запросе, расшифровывает их и предупреждает о проблемах (например, если срок действия JWT-токена уже истек или пароль передается в открытом виде без HTTPS).
- **Caching (Кэширование)** — простыми словами показывает, разрешено ли браузеру сохранять этот ответ в кэш, свежий ли он и когда истечет срок хранения.
- **SSE (Потоковые ответы и нейросети)** — незаменима при работе с ChatGPT, Claude, Gemini и другими потоковыми сервисами: показывает приходящие кусочки по времени, а кнопка **«Собрать весь стрим LLM в один текст»** склеивает сотни мелких фрагментов в готовый читаемый ответ.
- **WS (WebSockets и ручная инъекция фреймов)** — показывает живую переписку в чатах, уведомлениях и играх: каждое сообщение со стрелочкой направления (от клиента `↑` или от сервера `↓`). Пока соединение открыто, прямо под лентой сообщений доступна форма **Inject WebSocket Frame**: выберите формат (`Text`, `JSON` с проверкой синтаксиса и кнопкой `Format JSON`, либо `Hex (Binary)`) и отправьте произвольный фрейм в сторону сервера (**Send to Server** / `Ctrl+Enter`) или в сторону подключённого клиента (**Send to Client**).
- **Multipart (Формы и файлы)** — раскладывает по полочкам отправленные веб-формы и показывает безопасные миниатюры прикрепленных растровых картинок (`PNG`, `JPEG`, `GIF`, `WebP`, `BMP`, `ICO`; изображения `SVG` исключены из встроенного рендера в целях безопасности).
- **gRPC / Proto и Hex** — помогают прочитать бинарные данные и сообщения Protobuf даже без файлов схем; вкладка **Hex** виртуализирована построчно с чёткой фиксированной сеткой байтов `00..0F` и `Decoded ASCII` без сдвига колонок и поддерживает правый клик для копирования строки/буфера в Hex или Base64.

### Статистика запроса и пофазные тайминги (вкладка `Statistics`)
В правом верхнем углу заголовка Инспектора можно переключиться с **`Inspectors`** на **`Statistics`** (либо просто кликнуть по показателю размера и длительности вроде `1.4 KB • 84ms`, или нажать кнопку `Statistics` на свёрнутой панели инспектора):
- **Для одной выбранной сессии:** отображает горизонтальную шкалу сетевых и прокси-фаз (`DNS`, `TCP`, `TLS`, `Send`, `Wait (TTFB)`, `Download`, паузы `Breakpoint` / `Script` / `AutoResponder`) с плавающим оверлей-тултипом при наведении на сегмент таймлайна, таблицу точных меток времени **`ACTUAL PERFORMANCE`** (в стиле Fiddler Classic), блок **`Bytes & Compression`** (сравнение «сырого» объёма по сети и распакованного тела, экономия в `%`, пропускная способность), карточку **`Connection & TLS`** (переиспользование keep-alive сокета `reused`/`cold`, `Server IP:port`, реальная версия TLS, шифр, ALPN и сертификат сервера) и сворачиваемую оценку **`Estimated Worldwide Performance`** для разных регионов мира.
- **Для нескольких выделенных строк (2+ сессии):** выделите диапазон через `Shift + ↑/↓`, `Ctrl + Клик` или `Ctrl+A` — панель автоматически переключится в режим **Multi-Session Statistics** со сводными KPI (`Request Count`, `Bytes Sent/Received`, `Overall Elapsed`, `Avg / P50 / P95 / P99` длительности и TTFB, `% Reused`), диаграммами по статус-кодам и типам контента (MIME) и списком самых медленных/крупных URL. Готовый отчёт можно скопировать в буфер кнопками **Copy Text** (формат Fiddler) или **Copy Markdown**.

> [!NOTE]
> Если тело запроса или ответа превышает `2 МБ`, FluxProxy бережет оперативную память и WebView2: крупное тело с диска подгружается по кнопке только при открытии, а текстовый редактор Monaco автоматически отключает рендеринг свыше `2 МБ`, предлагая кнопки **Открыть в HexViewer** или **Сохранить тело на диск** (также действует в *Session Diff*).

## 6. Фильтры: как убрать лишний шум и сберечь память

### Быстрый поиск и категории на верхней панели
- Введите часть адреса, домена, метода или кода ошибки в строку поиска (**`Ctrl+F`**). Кнопка **`.*`** рядом включает поиск по регулярным выражениям.
- Справа от строки поиска расположены кнопки быстрых категорий: **`All`** (все), **`JSON`**, **`SSE`**, **`Img`** (картинки), **`4xx/5xx`** (только ошибки), **`WS`**, **`Mock`** (подмененные) и **`Marked`** (отмеченные вами).
- Кнопка **`Tail`** управляет автопрокруткой: когда она включена, список сам прокручивается к самым свежим запросам; если вы листаете список вверх, автопрокрутка не мешает чтению.

### Расширенные фильтры (`Alt+4` или кнопка `Filter`)
Если нужно настроить отбор точнее, откройте раздел **Settings → Filters** (`Alt+4` или **Rules → Filters**):
1. **Готовые пресеты** — переключатели в один клик:
   - *«Только API бэкенда»* — убирает картинки, шрифты, стили, JS-скрипты и служебные запросы, оставляя чистые обращения за данными;
   - *«Скрыть аналитику и фоновый шум ОС»* — прячет системную телеметрию, проверки обновлений Windows/macOS и рекламные счетчики;
   - *«Медленные и тяжелые»* — находит запросы дольше 500 мс, ответы тяжелее 1 МБ и ошибки сервера;
   - Вы также можете сохранить свою комбинацию настроек как собственный пресет.
2. **Списки сайтов (Hosts List)** — вставьте список нужных доменов (по одному в строке, поддерживаются маски вроде `*.mycompany.ru`), выберите режим **Whitelist** (показывать *только* их) или **Blacklist** (скрыть их).
3. **Матрица условий (Filter Matrix)** — позволяет собрать любое правило из выпадающих списков, например: *«Показать запросы, где метод = POST и время ответа > 300 мс»*.
4. **Пороги шума (Thresholds)** — быстрые галочки для скрытия ответов `304 Not Modified`, проверочных `OPTIONS`-запросов, туннелей `CONNECT`, а также **4 независимых тумблера статических ассетов и скриптов** (**Скрывать CSS**, **Скрывать Images**, **Скрывать Fonts**, **Скрывать JavaScript (JS)** — файлы `.js`, `.mjs`, `.cjs`, `.jsx`, `.js.map` без ложного скрытия `.json`) с быстрыми кнопками-чипами **Скрыть всё (4)**, **Только статика (CSS / Img / Fonts)** и **Сбросить**. *(Старые профили с флагом `hideStaticAssets` автоматически мигрируют на CSS/Images/Fonts без внезапного скрытия JS.)*

### Контроль памяти при долгой работе (`Keep`, `Drop Non-Matching` и SQLite)
Если вы оставляете FluxProxy включенным на несколько часов:
- **Переключатель `Keep` на панели инструментов** задает, сколько последних запросов держать в оперативной памяти (например, `500`, `1 000`, `10 000` или любое свое число через пункт *Custom…*). Более старые записи автоматически вытесняются в локальную базу SQLite и остаются доступными при открытии в Инспекторе.
- **Режим «Не сохранять лишнее» (`Drop Non-Matching`)** — включается в меню кнопки `Keep` или через **Tools → Session Retention Limit → Drop Non-Matching on Capture**. Когда эта галочка активна, все запросы, не подходящие под ваши текущие фильтры, **отбрасываются сразу на входе** и вообще не занимают память. В правой части нижней строки состояния вы всегда видите, сколько сессий сейчас в памяти и сколько фонового шума было отсеяно (`Dropped`).
- **Очистка и сжатие базы SQLite (`VACUUM`):** если архивная база на диске выросла, нажмите прямо на индикатор **`SQLite: X.X MB`** в нижней строке состояния (или выберите **File / Tools → Purge SQLite Archive (Free Disk)…**) — программа удалит старые архивные записи с диска и сожмет файл базы, полностью сохраняя текущие сессии в RAM и их выгруженные тела (`> 2 МБ`). В настройках (`Ctrl+,` → *General*) или прямо в этом окне можно также включить **Clear DB on App Exit** для автоматической очистки и сжатия при каждом закрытии FluxProxy.

## 7. Если перестали работать мессенджеры, банки или mTLS (Избирательный HTTPS и сертификаты)

Некоторые приложения с повышенной защитой — например, Telegram, WhatsApp, банковские клиенты, платежные шлюзы, игры с античитом или системные службы Apple и Windows — жестко проверяют подлинность сервера и **отказываются работать**, если видят между собой и сервером любой отладочный прокси. А внутренние корпоративные и финансовые API часто дополнительно требуют **клиентский сертификат (mTLS)**.

Во FluxProxy эти задачи решаются в пару кликов:

### Способ 1 (Рекомендуемый): Расшифровывать только нужные вам сайты
Вместо того чтобы вмешиваться во весь интернет-трафик компьютера, скажите программе расшифровывать **только те сайты, которые вы сейчас тестируете**:
1. На верхней панели инструментов нажмите на переключатель режима HTTPS (или в меню **Rules → Selective MITM: Targeted Allowlist**).
2. Включите режим **Targeted Only** и добавьте домен вашего проекта (например, `*.my-app.dev`).
3. Либо просто кликните правой кнопкой мыши по нужному запросу в таблице и выберите **Always inspect (`ваш-домен`)**.

Теперь ваш рабочий сайт полностью виден во всех деталях, а все остальные приложения, мессенджеры и игры идут напрямую (с бейджем **`TUNNEL`** в таблице) без единой ошибки!

### Способ 2: Добавить капризное приложение, PKI или видео-CDN в список обхода (Selective MITM 2.0)
Если вам удобнее расшифровывать всё подряд, но конкретный сервис выдает ошибку соединения или вы хотите пустить тяжелое потоковое видео напрямую:
- Кликните правой кнопкой мыши по его строке в таблице и выберите **Always passthrough (`домен`)**. Переключение срабатывает мгновенно — уже открытые фоновые туннели к этому домену аккуратно сбрасываются без перезапуска браузера.
- Или откройте **Rules → TLS Bypass** (**Settings → TLS & Mobile → MITM & TLS Bypass**):
  - Подключите в один клик **11 готовых наборов (Quick-Packs)**: *Dev Tools & Package Managers*, *OCSP / CRL PKI*, *Payment Gateways & 3-DS*, *DRM & Audio/Video Streaming*, *Gaming & Anti-Cheat*, *РФ FinTech & Госуслуги*, *Google & Android FCM*, *Apple Ecosystem & APNs*, *Windows Updates & Telemetry*, *E2EE & Corporate Messengers* и *Видеохостинги / CDN (YouTube, Googlevideo, Twitch, Vimeo)*.
  - Используйте переключатель **`Table View`** ↔ **`Bulk Text Editor`** для пакетной правки доменов (поддерживаются комментарии `#`, маски `*` и `regex:`), кнопку **`Quick Paste…`** для вставки списка адресов из буфера, групповые чекбоксы, импорт/экспорт **`.txt` / `.json`** и кнопку **`Сброс PKI/OCSP`** для восстановления рекомендованных правил.
  - Для обнаруженных в текущей сессии хостов отображаются быстрые чипы **`+ Target` / `+ Bypass`**, а напротив каждого правила виден счётчик реальных срабатываний **`Hits: N`**.

### Клиентские сертификаты для защищённых API (mTLS, `Ctrl+Shift+C`)
Если сервер при подключении запрашивает ваш персональный клиентский сертификат (**Mutual TLS**):
1. Нажмите **`Ctrl+Shift+C`** или выберите **Tools → Client Certificates** (открывает **Settings → TLS & Mobile → Client Certificates**, также доступно через `Ctrl+K` по команде `mtls`).
2. Укажите **маску домена** (например, `api.corp.local` или `*.corp.local`), при желании задайте понятную метку и выберите файл сертификата через **Обзор…**: поддерживаются контейнеры **PKCS#12 (`.p12` / `.pfx`)** с паролем и **PEM (`.pem` / `.crt` / `.cer`)** с опциональным файлом приватного ключа (`.key`).
3. Для повышенной секретности (например, с корпоративными ключами) можно отметить опцию **`Session-only (In-Memory, do not save key to disk)`** — такой сертификат получит метку **`RAM ONLY`**, будет храниться исключительно в оперативной памяти до закрытия программы и **никогда не запишется на диск**.
4. Добавленный сертификат появится в таблице с извлечённым **Common Name (CN)** и датой окончания срока действия (с предупреждением, если сертификат просрочен или скоро истекает). Правила можно временно включать/отключать переключателем или удалять.

> [!NOTE]
> В целях безопасности сохранённые постоянные ключи на Windows (включая расшифрованные в памяти контейнеры PKCS#12 `.p12`/`.pfx` и PEM-ключи) сохраняются в локальное хранилище исключительно в зашифрованном виде (`{id}.identity.pem`) средствами ОС через **Windows DPAPI** (`FLUX_DPAPI_V1:`) без хранения сырых незашифрованных `.p12`/`.pfx` дубликатов (а устаревшие дубликаты автоматически очищаются при загрузке); на Unix ключи защищаются правами `0600`. Сами сертификаты, пароли и приватные ключи **не включаются** при экспорте профиля настроек `fluxproxy-settings-v1.json`.

## 8. Перехват на паузе и подмена ответов сервера

### Пауза и ручная правка на лету (Breakpoints, `Alt+6`)
Точки останова работают в полноценной **неблокирующей вкладке `Breakpoints` (`Alt+6`)**: пока запрос стоит на паузе, вы можете свободно переключиться в `Traffic` или `TextWizard`, а верхний баннер вернёт вас к ожидающему пакету в один клик (тела крупнее `256 KiB` выгружаются в SQLite и подгружаются только при выборе нужного пакета в очереди):

1. **Поймать запрос перед уходом на сервер:** нажмите **`F11`** (или кнопку паузы запроса на панели). Отправьте форму на сайте — пакет появится во вкладке **Breakpoints** (а вверху загорится баннер). Поменяйте метод, заголовки или текст запроса и нажмите **Execute / Continue**.
2. **Поймать ответ сервера перед показом в браузере:** нажмите **`Alt+F11`**. Когда сервер ответит, вы сможете переписать текст ответа или одним кликом нажать кнопку ошибки (**`500`**, **`403`**, **`404`**, **`502`**), чтобы проверить, покажет ли ваш сайт понятное сообщение пользователю.
3. **Ловить не всё подряд, а только один адрес:** нажмите **`Ctrl+K`**, введите `bpu /api/orders` и нажмите `Enter` — на паузу будут вставать только запросы к `/api/orders`, не мешая загрузке остальной страницы. Аналогично команда `bpafter /api/orders` ловит только ответы.
4. Чтобы мгновенно отключить все паузы и отпустить задержанные запросы, нажмите **`Shift+F11`**.

### Автоматическая подмена ответов (AutoResponder, `Alt+3`)
Если нужно, чтобы определенный адрес **всегда** возвращал заготовленный вами ответ (например, сервер еще не написан разработчиками или нужно много раз воспроизвести редкую ситуацию):

1. Самый простой путь: кликните правой кнопкой мыши по похожему запросу в таблице и выберите **«Создать правило AutoResponder»**.
2. Откроется готовое правило, куда уже скопированы адрес и пример ответа.
3. Выберите, что должно происходить при совпадении адреса (*Rule Action*):
   - **Mock Local Response** — сразу вернуть ваш собственный статус, заголовки и JSON-ответ без обращения к реальному серверу;
   - **Forward & Override Status** — выполнить настоящий запрос, но заменить код ответа (например, на `429`);
   - **Inject Latency Only** — ничего не менять в данных, но искусственно задержать ответ на нужное число миллисекунд (поле *Latency*), чтобы проверить, как выглядят индикаторы загрузки при медленном интернете.
4. Нажмите **Apply Rule**. Включать и временно выключать весь автоответчик целиком можно одним переключателем в шапке раздела AutoResponder или в настройках (`Ctrl+,`).

### Автоматическая правка заголовков (без кэша, без ошибок CORS, смена устройства)
- Чтобы браузер всегда запрашивал свежие данные с сервера, а не брал из кэша, включите **Rules → Disable Caching (Strip ETag / IMS)** (или соответствующую кнопку на панели).
- В разделе **Settings → Filters → Headers** (`Alt+4` или **Rules → Filters**) можно одной кнопкой включить автоматическое добавление заголовков **CORS** (для локальной разработки фронтенда) или притвориться мобильным браузером iPhone / Android с помощью готовых шаблонов **User-Agent**.

### Программируемая обработка на Python (`Scripts`, `Alt+5`)
Когда статических правил AutoResponder и Header Mutations недостаточно — например, нужно вычислять динамические HMAC-подписи, условно патчить поля JSON, перенаправлять запросы между серверами или возвращать сложные моки по условию — откройте вкладку **Scripts (`Alt+5`)** (встроенный **Python Scripting Engine** с хуками `on_request` и `on_response`). Подробные примеры, справочник API и ограничения описаны в отдельном [**Руководстве по Python Scripting Engine (`PYTHON_SCRIPTING_GUIDE.md`)**](PYTHON_SCRIPTING_GUIDE.md).

## 9. Отправка своих запросов, генератор кода, OpenAPI и сравнение

### Конструктор запросов (Composer, `Alt+2` или клавиша `E`)
Полноценная рабочая вкладка для ручного составления, модификации и повторной отправки HTTP/HTTPS-запросов (как в Fiddler Classic и Postman):
- **Мгновенное открытие из Traffic (`E`):** выберите любую строку в таблице `Traffic` и нажмите клавишу **`E`** (или перетащите строку мышкой на иконку **Composer** в левой боковой панели) — откроется вкладка **Composer** с загруженным запросом, бейджем **`From #<id>`**, кнопкой **`← Traffic` (`Alt+1`)** и быстрым переходом **`Inspect #<id> in Traffic`**.
- **Сплит Request / Response и таймаут:** выберите метод (`GET`, `POST`, `PUT`, `DELETE` и др.), отредактируйте адрес, заголовки (включая ПКМ-меню строк заголовков) и тело запроса и нажмите **Send** — ответ отобразится в соседней ресайзабельной панели. Долгий запрос можно в любой момент прервать кнопкой **`Cancel`** и задать отдельный лимит ожидания прямо рядом с кнопкой отправки (глобально настраивается в **Settings → Network & Routing → Timeouts**).
- **Интеграция с Python-скриптами (`Run Python Scripts`):** по умолчанию запросы из Composer и повтор (`R` / `Ctrl+R`) автоматически проходят через активные хуки `on_request` / `on_response` (например, чтобы пересчитались HMAC-подписи или токены). Снимите галочку **`Run Python Scripts`**, если нужно отправить «сырой» запрос в обход скрипта.
- **Умный импорт из cURL (`Import cURL`):** нажмите кнопку **Import cURL** в шапке Composer, вставьте команду `curl` из Chrome DevTools, Postman или терминала (поддерживаются POSIX Bash `\`, Windows cmd `^` и PowerShell) и нажмите **Import into Composer**. Ещё быстрее — **просто вставьте строку `curl ...` в поле URL** (`Ctrl+V` или ПКМ → *Paste & Import cURL*), и FluxProxy автоматически заполнит метод, адрес, заголовки, cookies, Basic-авторизацию и тело запроса!

### Генератор клиентского кода (`Code Generator`)
Любой захваченный запрос или черновик в Composer можно в один клик превратить в готовый код для вашего проекта:
1. Нажмите кнопку **Code** в Composer, выберите **Edit → Code Generator**, кликните правой кнопкой мыши по строке в таблице трафика или вызовите команду через **`Ctrl+K`**.
2. Выберите нужный язык и библиотеку (поддерживаются **5 языков / 8 вариантов**):
   - **JavaScript:** `fetch`, `axios`
   - **Python:** `requests`, `httpx`
   - **Go:** `net/http`
   - **Rust:** `reqwest`
   - **cURL:** `Bash`, `PowerShell`
3. Проверьте подсвеченный код в полноэкранном окне Monaco Editor и нажмите **Copy Code**.

### Автоматическая генерация спецификации OpenAPI 3.0.3 / Swagger
Чтобы быстро задокументировать API на основе реального перехваченного трафика:
1. Выделите нужные HTTP/HTTPS-сессии в таблице (или оставьте выделение пустым, чтобы обработать все захваченные API-запросы) и выберите **File → OpenAPI Export** либо соответствующий пункт в контекстном меню таблицы (также доступно в `Ctrl+K`).
2. Задайте название, версию API, формат (**`YAML`** или **`JSON`**) и при необходимости отметьте **Include Examples**.
3. FluxProxy автоматически объединит эндпоинты и разные статус-коды (`200`, `4xx`, `5xx`), параметризует числовые ID и UUID в путях (`{id}` / `{uuid}`), синтезирует JSON Schema и вынесет заголовки `Authorization`, `Cookie` и `X-Api-Key` в `components.securitySchemes` **без вставки реальных секретных токенов** — готовую спецификацию можно скопировать или сохранить в файл.

### Сравнение двух запросов (Session Diff, `Ctrl+D`)
Представьте: вчера запрос возвращал `200 OK`, а сегодня такой же запрос выдает `400 Bad Request` или `403 Forbidden`. Вручную искать разницу среди десятков заголовков и полей JSON долго:
1. Зажмите `Ctrl`, кликните по двум строкам в таблице и нажмите **`Ctrl+D`** (или просто выберите одну строку и нажмите `Ctrl+D` — программа сама подберет для сравнения похожий запрос к тому же адресу с другим результатом!).
2. Откроется **неблокирующая вкладка Session Diff** (выбранная пара A/B сохраняется при переключении обратно в `Traffic`), где все отличия подсвечены цветом отдельно по заголовкам, кукам/токенам, телу запроса и ответу.
3. Включите галочки **Sort Keys & Headers** (отсортировать поля по алфавиту) и **Ignore Volatile Headers** (скрыть меняющиеся каждую секунду даты и технические ID), чтобы увидеть только реальную суть отличий.

### Декодер текста и токенов (TextWizard, `Ctrl+E`)
Неблокирующая вкладка для расшифровки и преобразования непонятных строк без перехода на сторонние сайты (куда небезопасно вставлять рабочие токены и пароли); введённый текст и выбранный инструмент сохраняются при возврате в `Traffic` или `Composer`:
- **JWT Inspect** — вставьте токен авторизации (`eyJ...`), чтобы увидеть зашитые в него права пользователя и точный таймер, сколько минут осталось до истечения токена. *(Совет: токен можно вставить даже сразу в командную строку `Ctrl+K`!)*
- **Base64** и **URL Codec** — кодирование и раскодирование строк и ссылок в обе стороны.
- **Compression** — сжатие и распаковка текста в форматах **Gzip**, **Brotli**, **Deflate** и **Zstd (Zstandard)** с подсчетом экономии размера. *(Современные сайты и CDN, отдающие ответы с заголовком `content-encoding: zstd`, также автоматически распаковываются FluxProxy на лету для браузера и Инспектора.)*
- **Hex** — перевод текста в байтовый вид и обратно.
- **Timestamp** — мгновенный перевод чисел времени Unix (вроде `1731150000`) в понятную дату и время в вашем часовом поясе.

## 10. Проверка трафика со смартфона или планшета (iOS и Android)

Чтобы посмотреть, какие запросы отправляет браузер или приложение на вашем телефоне, убедитесь, что **телефон и компьютер подключены к одной и той же Wi-Fi сети**, и выполните 4 простых шага:

1. На компьютере во FluxProxy нажмите **`Ctrl+Shift+M`** (или выберите **Tools → Mobile Setup** — откроется **Settings → TLS & Mobile → Mobile Setup**).
2. В открывшейся панели включите прием внешних подключений (`0.0.0.0`), если программа предложит это сделать — либо выберите в **Settings (`Ctrl+,`) → General** **конкретный Wi-Fi / LAN-адаптер (`Specific Interface`)**, чтобы не открывать порт в публичных или VPN-сетях. На экране появятся адрес вашего компьютера в сети (например, `192.168.1.45`), порт (`8888`) и большой **QR-код**.
3. На смартфоне откройте настройки вашей текущей Wi-Fi сети, найдите пункт **Прокси (HTTP-прокси) → Вручную** и впишите указанные на экране **Сервер (IP)** и **Порт**.
4. Установите сертификат на телефон:
   - Наведите камеру телефона на **QR-код** на экране компьютера (или откройте в браузере телефона короткий адрес `http://flux.proxy`).
   - **На iPhone / iPad:** скачайте профиль → откройте *Настройки → Профиль загружен → Установить*, а затем обязательно включите доверие в *Настройки → Основные → Об этом устройстве → Доверие сертификатам*.
   - **На Android:** скачайте сертификат `.crt` и установите его через *Настройки → Безопасность → Шифрование и учетные данные → Установка с накопителя → Сертификат CA*. *(Примечание: современные приложения на Android по умолчанию доверяют системным сертификатам только в тестовых/отладочных сборках — готовый кусочек настроек для разработчика также можно скопировать прямо из окна мастера).*

Готово! Все запросы с телефона появятся в таблице с заметным зеленым значком смартфона 📱. Нажмите на этот значок в любой строке, чтобы скрыть трафик компьютера и видеть только свой телефон.

### Ограничение доступа по белому списку (`LAN Client Allowlist`)
Если вы тестируете мобильное устройство в общей корпоративной или офисной Wi-Fi сети и хотите ограничить доступ к порту FluxProxy **только вашими устройствами**:
- В том же окне **`Mobile Setup` (`Ctrl+Shift+M`)** в блоке **`LAN Client Allowlist (Белый список устройств)`** добавьте разрешённые IPv4/IPv6-адреса или CIDR-подсети (например, `192.168.1.45` или `192.168.1.0/24`).
- Или кликните правой кнопкой мыши по строке уже подключившегося телефона в таблице трафика и выберите **`Разрешить IP в LAN Allowlist (<IP>)`**.
- Пока список пуст, подключаться могут любые LAN-клиенты. Как только добавлен хотя бы один адрес, все посторонние внешние устройства сразу получают `403 Forbidden` ещё до записи в журнал сессий, тогда как локальный компьютер (`127.0.0.1` / `::1`) остаётся разрешён всегда.

> [!NOTE]
> В целях сетевой безопасности внешние LAN-устройства не имеют доступа через прокси к локальным и link-local сервисам компьютера (`localhost`, `127.0.0.1`, `::1`, loopback/link-local диапазоны): проверка выполняется **как по имени хоста, так и после реального DNS-разрешения** (защита от DNS rebinding вроде `lvh.me` / `nip.io` с изолированным пулом соединений), а сохранённые на компьютере клиентские сертификаты mTLS не используются.

> [!IMPORTANT]
> **Не забудьте после завершения проверки** вернуть настройку прокси в свойствах Wi-Fi на телефоне обратно в положение **«Выкл.» (Авто)** — иначе при выключенном на компьютере FluxProxy телефон не сможет выходить в интернет через эту Wi-Fi сеть.

## 11. Виртуальный DNS (HOSTS Remapping), замедление сети и Upstream Proxy

### Виртуальный DNS без правки системного `hosts` (`Ctrl+Shift+H`)
Когда нужно направить запросы к продакшен- или стейджинг-домену (`api.prod.example.com` или `*.staging.local`) на локальный сервер (`127.0.0.1:3000`) без прав администратора и без поломки HTTPS-сертификата:
1. Нажмите **`Ctrl+Shift+H`** (или откройте **Tools → HOSTS Remapping**, либо **Routing** на тулбаре → **Settings → Network & Routing → HOSTS Remapping**).
2. Введите исходный домен или wildcard-маску, целевой IP/хост и (при необходимости) целевой порт.
3. Оставьте включённой опцию **Preserve `Host` header**, если вашему локальному бэкенду нужен оригинальный заголовок `Host` — при этом FluxProxy сохраняет оригинальный TLS SNI и маркирует такие запросы бейджем **`REMAP`** в таблице.

### Эмуляция медленной сети и офлайна (Bandwidth Throttling)
Чтобы проверить поведение фронтенда, мобильного приложения или таймаутов при плохом интернете:
1. Нажмите на всегда видимый селектор **`Throttle`** на верхней панели инструментов (по умолчанию **`Throttle: Off`**), перейдите в **Settings → Network & Routing → Throttling** или откройте список пресетов через **`Ctrl+K`** (по запросу `throttle`).
2. Выберите готовый профиль: **`GPRS`** (`50 Kbps · 500 ms`), **`Slow 3G`** (`400 Kbps · 400 ms`), **`Fast 3G`** (`1.6 Mbps · 150 ms`), **`LTE / 4G`** (`30 Mbps · 40 ms`), **`Offline`** (немедленно отвечает `HTTP 503`) или задайте точные лимиты **↓ Kbps / ↑ Kbps / RTT ms** в блоке **Custom Profile** и нажмите **Apply Custom Limits**.
3. Пока ограничение активно, в нижней строке состояния горит цветной индикатор профиля — нажмите на него в любой момент, чтобы мгновенно вернуть полную скорость.

### Каскадирование через корпоративный или внешний прокси (`Ctrl+Shift+U`)
Если ваш компьютер выходит во внешнюю сеть через корпоративный прокси или локальный туннель:
1. Нажмите **`Ctrl+Shift+U`** (или откройте **Tools → Upstream Proxy**, либо **Routing** на тулбаре → **Settings → Network & Routing → Upstream Proxy**).
2. Включите маршрутизацию, выберите протокол (**`HTTP`**, **`HTTPS`** или **`SOCKS5`**), укажите хост, порт и при необходимости логин/пароль. Для таких соединений в колонке `Server IP` и карточке `Connection & TLS` отображается шлюз **`via <ip>:<port>`**.
3. В поле **Bypass List** перечислите адреса, которые должны идти напрямую мимо вышестоящего прокси (поддерживаются `localhost`, `<local>`, CIDR-подсети, маски `*.internal`, glob и `host:port`).

> [!NOTE]
> Пароль от `Upstream Proxy` хранится исключительно в оперативной памяти программы на время текущего запуска и **никогда не записывается** при экспорте профиля `fluxproxy-settings-v1.json`.

### Настройка сетевых таймаутов (`Upstream Timeouts`)
Во вкладке **Settings (`Ctrl+,`) → Network & Routing → Timeouts** можно отдельно настроить три порога ожидания (по аналогии с Fiddler / Charles):
- **Connect Timeout (s)** *(по умолчанию `15` с)* — время на DNS-резолвинг, TCP Connect и TLS Handshake.
- **Response Headers / TTFB (s)** *(по умолчанию `0` = Unlimited)* — ожидание первого заголовка ответа от сервера без искусственного обрыва долгих AI-стримов или медленных отчётов. При преждевременном закрытии вкладки браузером/клиентом прокси корректно фиксирует в таблице код `499`.
- **Composer Timeout (s)** *(по умолчанию `120` с)* — таймаут ручных запросов из Composer (отменяемых кнопкой **`Cancel`**).

## 12. Сохранение файлов, обмен с коллегами и настройки программы

### Как сохранить перехваченный трафик и отправить коллеге
- **Сохранить все сессии (`Ctrl+S` или File → Save All Sessions As…):** по умолчанию выгружает **текущее окно таблицы (RAM)** в выбранный формат; если старые записи уже были вытеснены в SQLite, в **Sanitized Export** можно включить опцию **«Включить вытесненные в SQLite (N)»** для потоковой выгрузки полного архива с диска:
  - **`.har` (HTTP Archive)** — универсальный формат с реальными пофазными таймингами (`dns` / `connect` / `ssl` / `wait` / `receive`), который открывается не только во FluxProxy, но и в любом браузере Chrome / Edge / Firefox (вкладка *Network → Import HAR*), а также в Postman и Charles;
  - **`.saz`** — родной архив классического Fiddler Classic (с заполнением `<SessionTimers>` и `<PipeInfo>`);
  - **`.json`** — полный внутренний формат FluxProxy.
- **Сохранить только нужные запросы:** выделите одну или несколько строк в таблице → кликните правой кнопкой мыши → **Save Selected as HAR (`.har`)** или **Save Selected as Fiddler SAZ (`.saz`)** (либо через меню *File → Save Selected Sessions…*).
- **Безопасный экспорт без токенов и паролей (`Ctrl+Shift+S` или File → Export Sanitized Sessions…):** если архив нужно приложить к публичному тикету или отправить коллегам, используйте окно **Sanitized Export** (включая галочку **«Включить вытесненные в SQLite»** при наличии архивных записей на диске). Оно поддерживает форматы `.har`, `.saz`, `.json` и Raw HTTP (`.txt`), а также готовые пресеты **Safe Sharing**, **Strict Anonymization** и **Custom** — программа потоково заменит заголовки авторизации, куки и редиректы (`Authorization`, `Cookie`, `Set-Cookie`, `X-Api-Key`, а также query-параметры в `Location` и `Referer`), секретные поля внутри JSON, веб-форм (включая многострочный `form-urlencoded` и **`multipart/form-data`** с вложенными JSON-частями, а также `camelCase`-ключи вроде `accessToken`, `apiKey`, `clientSecret`, `password`, `token`, `secret`, `cvv`), события **SSE** и фреймы **WebSocket** (включая SignalR, Socket.IO и токены Bearer/JWT), учетные данные `userinfo` и `#fragment` в URL, чувствительные query-параметры и (при необходимости) IP/имя процесса клиента на `[REDACTED]`, сохраняя валидную структуру архива.
- **Открыть чужой архив (`Ctrl+O` или File → Open / Import Archive…):** выберите файл `.har`, `.saz` или `.json` на диске — либо **просто перетащите этот файл мышкой прямо в окно FluxProxy**!
- **Скачать картинку, файл или ответ отдельно:** кликните правой кнопкой мыши по строке в таблице и выберите **Save Response Body As…** (или **Save Request Body As…**) — программа сама предложит подходящее расширение файла (`.json`, `.png`, `.html` и др.).
- **Локальная база SQLite:** если вы хотите быстро делать снимки текущего рабочего сеанса внутри программы без выбора файлов на диске, используйте пункты **File → Save Archive to SQLite** и **Restore Archive from SQLite**, а для освобождения места на диске — **File / Tools → Purge SQLite Archive (Free Disk)…**.

### Настройки программы и перенос профиля (`Settings Hub`, `Ctrl+,`)
Нажмите **`Ctrl+,`** (или откройте **File → Settings**, либо иконку шестерёнки внизу левой боковой панели), чтобы открыть единый полноэкранный центр настроек со **сквозным поиском** по параметрам и 6 разделами:
- **General** — **смена порта прокси** (выбранный порт запоминается в `proxy_port.pref` для следующих запусков), **выбор сетевого интерфейса привязки (`Bind Host`)** (`Loopback 127.0.0.1`, `All Interfaces 0.0.0.0` или `Specific Interface` — Wi-Fi, Ethernet, WSL, Docker или VPN-адаптер с режимом **Dual Listener**), лимиты памяти и автоочистка SQLite при выходе.
- **Network & Routing** — профили **Throttling**, правила **HOSTS Remapping (`Ctrl+Shift+H`)**, каскадирование **Upstream Proxy (`Ctrl+Shift+U`)** и раздельные **Upstream Timeouts**.
- **TLS & Mobile** — режим HTTPS MITM и списки **TLS Bypass**, хранилище клиентских сертификатов **mTLS (`Ctrl+Shift+C`)** и мастер **Mobile Setup (`Ctrl+Shift+M`)** с `LAN Client Allowlist`.
- **Filters (`Alt+4`)** — матрица фильтров (**Matrix**), списки доменов (**Hosts List**), пороги шума (**Thresholds**) и мутации заголовков (**Headers**).
- **Appearance & Layout** — 8 тем-пресетов, редактор цветовой палитры, компактный тулбар, расположение инспектора и колонки таблицы.
- **Diagnostics & Backup** — самодиагностика **Proxy Doctor (`Ctrl+Shift+D`)**, кнопка **Reset to Defaults** и **Profile Backup**:
  - Через **Settings → Diagnostics & Backup → Profile Backup** (или меню **File → Export / Import Settings Profile**) вы можете выгрузить абсолютно все свои настройки, выбранную тему-пресет и кастомную палитру цветов, сохраненные фильтры, списки доменов, правила автоответчика, точки останова (Breakpoints), правила **HOSTS Remapping**, профиль **Bandwidth Throttling**, **`Upstream Timeouts`**, **`LAN Client Allowlist`**, беспарольные настройки **Upstream Proxy**, код и статус встроенного Python-скрипта ([`PYTHON_SCRIPTING_GUIDE.md`](PYTHON_SCRIPTING_GUIDE.md)), параметры санитизации экспорта и ориентацию панелей в один аккуратный файл `fluxproxy-settings-v1.json`. При загрузке файла на другом компьютере программа заранее покажет наглядную сводку того, какие настройки будут применены; если профиль содержит Python-скрипт, в окне превью выводится предупреждение безопасности, и по умолчанию скрипт импортируется **выключенным** (если вы явно не отметите галочку доверия источнику). *(Клиентские сертификаты mTLS — как постоянные, так и `RAM ONLY` — и пароль Upstream Proxy не попадают в экспортируемый файл.)*

### Подключение программ из командной строки (терминала)
Консольные утилиты (`curl`, `python`, `node`, `npm`, `git`) обычно не смотрят на системный прокси Windows/macOS. Чтобы увидеть их запросы во FluxProxy, выберите в меню **Help → Copy CLI HTTP_PROXY Snippet** и вставьте скопированную команду в окно терминала перед запуском вашей программы.

## 13. Частые вопросы и решение проблем

**Захват включен, но что-то не работает (или в статусе появилась ошибка)**
> Запустите встроенный диагностический мастер **Proxy Doctor**: нажмите **`Ctrl+Shift+D`** (или выберите **Help → Proxy Doctor**, либо нажмите кнопку **`Fix with Proxy Doctor`** в строке состояния). За секунду программа проверит занятость порта прокси, доверие к Root CA, синхронизацию системного прокси ОС (включая корпоративные политики Windows GPO `ProxySettingsPerUser = 0` с подсказкой флага `--proxy-server` для браузера, KDE `kioslaverc` и подсказку `HTTP_PROXY` для Linux WM без DE), конфликты с VPN/TUN-адаптерами, брандмауэр Windows, внешний корпоративный SSL/EDR-инспектор (`Zscaler` / `Kaspersky` / `EDR` при несовпадении SHA-256 пробника) и сквозной тестовый запрос к `http://flux.proxy/health`. Все типовые сбои исправляются в один клик кнопкой исправления напротив проверки или общей кнопкой **Fix All Fixable**.

**Браузер пишет «Подключение не защищено» (`NET::ERR_CERT_AUTHORITY_INVALID`) на всех сайтах**
> Корневой сертификат еще не установлен. Откройте **Tools → Root CA** и нажмите **Trust Root CA in OS Store**, после чего перезапустите вкладку сайта. Если ошибка только в браузере **Firefox** — импортируйте файл сертификата в собственных настройках Firefox (см. [Шаг 2 быстрого старта](#шаг-2-установите-сертификат-для-защищенных-сайтов-https)).

**Захват включен, но в таблице не появляется ни одного запроса**
> Проверьте три вещи:
> 1. Включен ли системный прокси — индикатор **`SysProxy: ON`** в правой верхней или нижней части окна должен гореть зеленым.
> 2. Не остался ли текст в строке быстрого поиска (`Ctrl+F`) или активный жесткий фильтр — нажмите кнопку сброса фильтров, если счетчик показывает, что сессии скрыты.
> 3. Если вы проверяете локальный сайт на `localhost` / `127.0.0.1`, некоторые браузеры по умолчанию не пускают локальные адреса через системный прокси — попробуйте обратиться по локальному имени или отправить запрос через встроенную вкладку **Composer (`Alt+2`)**.

**При включенном FluxProxy не подключается мессенджер, банковский клиент, игра или пакетный менеджер**
> Это срабатывает встроенная защита приложения от проксирования (Certificate Pinning). Кликните правой кнопкой мыши по строке этого приложения в таблице и выберите **Always passthrough**, либо переключите FluxProxy в режим избирательной расшифровки **Targeted Only** (см. [Раздел 7](#7-если-перестали-работать-мессенджеры-банки-или-mtls-избирательный-https-и-сертификаты)).

**После сбоя питания или принудительного закрытия перестал открываться интернет в браузере или на телефоне**
> - **На компьютере:** просто запустите и штатно закройте FluxProxy (или нажмите `F12`) — программа автоматически очистит настройки системного прокси.
> - **На смартфоне:** зайдите в настройки Wi-Fi на телефоне и переключите пункт *HTTP-прокси* из режима *«Вручную»* обратно в *«Выкл.»*.

## 14. Шпаргалка по горячим клавишам

Открыть эту подсказку прямо внутри программы можно в любой момент клавишей **`?`**. Также почти любое действие можно быстро найти по названию через командную строку **`Ctrl+K`** (`Cmd+K` на macOS).

### Главные клавиши управления

| Клавиши | Что делает |
| :--- | :--- |
| **`F12`** | Включить или поставить на паузу перехват трафика |
| **`Ctrl+K`** / `Cmd+K` | Открыть командную палитру (**Command Palette 2.0**) и команды QuickExec |
| **`Ctrl+,`** / `Cmd+,` | Открыть полноэкранный центр настроек (**Settings Hub**) |
| **`Ctrl+F`** / `Cmd+F` | Перейти в строку быстрого поиска по списку запросов |
| **`Ctrl+S`** / `Cmd+S` | Сохранить все запросы в файл (`.har`, `.saz`, `.json`) |
| **`Ctrl+Shift+S`** | Безопасный экспорт с очисткой токенов и PII (**Sanitized Export**) |
| **`Ctrl+O`** / `Cmd+O` | Открыть сохраненный архив запросов (`.har`, `.saz`, `.json`) |
| **`Ctrl+Shift+M`** | Открыть **Settings → Mobile Setup** (Wi-Fi / QR-код / LAN Allowlist) |
| **`Ctrl+Shift+C`** | Открыть **Settings → Client Certificates** (mTLS) |
| **`Ctrl+Shift+H`** | Открыть **Settings → HOSTS Remapping** (виртуальный DNS) |
| **`Ctrl+Shift+U`** | Открыть **Settings → Upstream Proxy** (HTTP / HTTPS / SOCKS5) |
| **`Ctrl+Shift+D`** | Открыть **Settings → Proxy Doctor** (диагностика) |
| **`Ctrl+Shift+T`** | Включить / выключить компактный однострочный тулбар (**Slim Toolbar**) |
| **`Ctrl+E`** / `Cmd+E` | Переключить вкладку **TextWizard** (JWT, Base64, URL, сжатие, Hex, Timestamp) |
| **`?`** | Показать полноэкранное окно со списком всех горячих клавиш (**Shortcuts**) |

### Работа со списком запросов

| Клавиши | Что делает |
| :--- | :--- |
| **`↑` / `↓`**, **`Home` / `End`** | Перемещение по списку запросов |
| **`Shift + ↑ / ↓`** или **`Ctrl + Клик`** | Выделить сразу несколько запросов |
| **`Ctrl+A`** / `Cmd+A` | Выделить все видимые запросы в таблице |
| **`Enter`** или **`Пробел`** | Открыть инспектор деталей / переключить фокус обратно в таблицу |
| **`Ctrl+1` … `Ctrl+6`** | Переключить вкладку активной панели Инспектора (*Headers*, *JSON/Raw*, *Cookies/Params*, *Auth*, *Raw*, *Hex*) |
| **`R`** или **`Ctrl+R`** | Повторить выбранный запрос заново (**Replay**) |
| **`E`** | Открыть и отредактировать выбранный запрос во вкладке **Composer** |
| **`Ctrl+D`** / `Cmd+D` | Переключить вкладку сравнения двух запросов (**Session Diff**) |
| **`M`** / **`U`** | Добавить цветную метку и комментарий (`M`) / убрать метку (`U`) |
| **`Ctrl+C`** / `Cmd+C` | Скопировать ссылку выбранного запроса |
| **`Delete`** / **`Backspace`** | Удалить выбранные запросы из списка |
| **`Ctrl+X`** / `Cmd+X` | Полностью очистить весь список запросов |

| **`Alt+1` … `Alt+6`** | Разделы: *Traffic* (`1`), *Composer* (`2`), *AutoResponder* (`3`), *Settings → Filters* (`4`), [*Scripts*](PYTHON_SCRIPTING_GUIDE.md) (`5`), *Breakpoints* (`6`) |
