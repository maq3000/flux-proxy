# 📖 Руководство пользователя FluxProxy

**FluxProxy** — это удобная настольная программа для просмотра, проверки и отладки сетевых запросов на компьютере и мобильных устройствах.

Если сайт выдает непонятную ошибку, мобильное приложение долго грузит экран, нужно посмотреть, какие данные уходят на сервер, или проверить работу интерфейса еще до того, как готов бэкенд — FluxProxy покажет каждый запрос изнутри и позволит менять данные прямо на лету.

## 1. Зачем нужен FluxProxy

В отличие от встроенной вкладки *Network* в браузере, FluxProxy умеет гораздо больше:
- **Видит трафик любых программ**, а не только одной вкладки браузера: настольных приложений, локальных серверов, скриптов и подключенных по Wi-Fi смартфонов.
- **Показывает, какая именно программа отправила запрос** (например, `chrome.exe`, `node.exe` или телефон в вашей сети).
- **Позволяет менять запросы и ответы без правки кода**: можно поставить соединение на паузу, вписать другие данные или подставить ошибку `500`, чтобы проверить, как отреагирует приложение.
- **Умеет сохранять и открывать полные записи трафика** (`.har` и `.saz`), чтобы приложить их к задаче для разработчика.

## 2. Быстрый старт за 3 минуты

### Шаг 1. Включите перехват трафика
При запуске FluxProxy сразу готов к работе на локальном порту `8888`.

1. Убедитесь, что кнопка захвата в левом верхнем углу горит зеленым (показывает `127.0.0.1:8888`). Включать и ставить захват на паузу удобно клавишей **`F12`**.
2. Чтобы браузеры и программы на вашем компьютере автоматически пустили свой трафик через FluxProxy, включите **системный прокси**:
   - Нажмите на индикатор **`SysProxy`** в верхней или нижней полосе окна (или выберите **File → Act as OS System Proxy**).
   - Когда вы закроете FluxProxy или поставите захват на паузу (`F12`), программа **сама вернет прежние сетевые настройки** вашей системы — вручную ничего выключать не придется.

### Шаг 2. Установите сертификат для защищенных сайтов (HTTPS)
Почти все современные сайты работают по защищенному протоколу HTTPS. Чтобы браузер доверял FluxProxy и не показывал экран *«Подключение не защищено»*, нужно **один раз** установить локальный сертификат программы:

1. В верхнем меню откройте **Tools → HTTPS Root CA Certificate…** (или нажмите иконку щита на панели инструментов).
2. Нажмите зеленую кнопку **Trust Root CA in OS Store** и подтвердите системный запрос.
3. Статус в окне сменится на **«Установлен (доверен ОС)»**. После этого Chrome, Edge, Safari и системные программы сразу начнут открывать HTTPS-сайты без ошибок.

> [!TIP]
> **Пользуетесь Mozilla Firefox?** Этот браузер не использует системное хранилище сертификатов. В том же окне нажмите кнопку копирования рядом с путем к файлу `.cer`, затем в Firefox откройте *Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов → Центры сертификации → Импортировать…*, выберите этот файл и отметьте доверие для веб-сайтов.

> [!NOTE]
> Если после завершения работы вы захотите полностью удалить сертификат программы из системы, откройте это же окно и нажмите **«Удалить сертификат из доверенных ОС»**.

### Шаг 3. Оставьте на экране только нужный сайт
Как только вы включите системный прокси, в таблицу начнут попадать десятки фоновых запросов от операционной системы, мессенджеров и вкладок браузера. Чтобы сразу сфокусироваться на деле:
- Нажмите **`Ctrl+F`** и начните вводить адрес нужного сайта (например, `my-shop.ru` или `/api/login`) — всё лишнее мгновенно скроется.
- Либо нажмите кнопку **`Filter`** справа от поиска и выберите готовый набор **«Только API бэкенда»**.

## 3. Как устроено окно программы и настройка под себя

Окно FluxProxy разделено на пять понятных областей:

- **Верхнее меню (`File`, `Edit`, `Rules`, `View`, `Tools`, `Help`)** — полный доступ ко всем функциям, сохранению архивов и настройкам.
- **Панель инструментов** — главные кнопки под рукой: пауза захвата, очистка списка, лимит сессий, строка быстрого поиска, категории трафика и точки останова.
- **Левая боковая панель** — переключение между разделами:
  - **Traffic Viewer (`Alt+1`)** — список всех перехваченных запросов;
  - **Request Composer (`Alt+2`)** — ручная сборка и отправка своих запросов;
  - **AutoResponder (`Alt+3`)** — правила автоматической подмены ответов;
  - **Filter Matrix (`Alt+4`)** — тонкая настройка фильтров и списков сайтов.
- **Таблица запросов** — живой поток всех перехваченных обращений к сети.
- **Инспектор (снизу или справа)** — подробное содержимое выбранного запроса и ответа сервера.
- **Строка состояния (внизу)** — подсказки о текущем режиме прокси, подключении телефонов и расходе памяти.

### Как сделать интерфейс удобнее под свой экран:
- **Работаете на небольшом экране ноутбука?** Включите компактную панель инструментов: **View → Customize Toolbar → Compact Toolbar**, а левую панель сверните клавишей **`Ctrl+B`**. В том же меню *Customize Toolbar* можно отключить группы кнопок, которыми вы не пользуетесь.
- **Удобнее смотреть детали справа, а не снизу?** На широкоформатных мониторах выберите **View → Dock Inspector on Right**.
- **Светлая или темная тема:** переключается через **View → Theme** (Темная, Светлая или как в системе).
- **Настройка колонок таблицы:**
  - Потяните границу заголовка колонки мышкой, чтобы изменить ширину.
  - **Дважды кликните** по границе колонки, чтобы она сама подстроилась под ширину текста.
  - Нажмите **правой кнопкой мыши по шапке таблицы**, чтобы скрыть ненужные колонки (например, *Protocol* или *Process*) или вернуть ширину по умолчанию.

## 4. Работа со списком запросов

Каждая строка в таблице — это один сетевой запрос и ответ на него.

### На что обращать внимание в строке:
- **Цвет статуса ответа:**
  - 🟢 **2xx (200, 201, 204)** — запрос прошел успешно;
  - 🔵 **3xx (301, 302, 304)** — перенаправление или ответ из кэша;
  - 🟠 **4xx (400, 401, 403, 404)** — ошибка в запросе или нет доступа;
  - 🔴 **5xx (500, 502, 503)** — ошибка на стороне сервера;
  - **`WAIT`** — запрос прямо сейчас стоит на паузе и ждет вашего решения.
- **Метки рядом с адресом:**
  - **`MOCK`** — ответ выдан не реальным сервером, а вашим правилом подмены в AutoResponder;
  - **`BYPASS`** — трафик прошел напрямую в зашифрованном виде без вмешательства прокси;
  - **`BP:REQ` / `BP:RES` / `BP-MOD`** — запрос пойман точкой останова или изменен вами вручную;
  - **`HDR`** — заголовки были автоматически изменены правилом фильтрации;
  - **`💬`** — к запросу добавлена ваша текстовая заметка.
- **Подсветка медленных запросов (колонка Time):** если сервер отвечает слишком долго (по умолчанию дольше `500 мс` — оранжевый огонек, дольше `1500 мс` — красный), программа сразу подсветит такие узкие места.
- **Клик по источнику (колонка Process):** нажмите прямо на имя программы (например, `postman.exe`) или на зеленый значок смартфона 📱 с IP-адресом — таблица тут же отфильтруется и покажет трафик только от этого устройства или приложения.

### Быстрые действия с запросом (правый клик мышью по строке):
- **Повторить запрос (`R` или `Ctrl+R`)** — заново отправить точно такой же запрос на сервер и посмотреть свежий ответ.
- **Открыть в Composer** — перенести запрос в редактор, чтобы подправить параметры и отправить вручную.
- **Сравнить в Session Diff (`Ctrl+D`)** — сравнить с другим запросом.
- **Скопировать ссылку (`Ctrl+C`)**, заголовки или **готовую команду `Copy as cURL`** (ее можно вставить в терминал или Postman, или переслать коллеге).
- **Пометить цветом и добавить заметку (`M`)** — выделите важный запрос цветом и подпишите комментарий (снять пометку — клавиша **`U`**).
- **Создать правило AutoResponder** — превратить этот ответ в шаблон для автоматической подмены в один клик.
- **Сохранить в файл** — выгрузить выбранные строки в архив `.har` / `.saz` или скачать само тело ответа (например, картинку или JSON).

## 5. Детальный разбор запроса и ответа (Инспектор)

Кликните по любой строке в таблице (или нажмите **`Enter` / `Пробел`**), чтобы открыть подробности. Одна половина инспектора показывает **что отправило ваше устройство (Request)**, а вторая — **что ответил сервер (Response)**.

### Основные вкладки на каждый день:
- **Headers** — все служебные заголовки с удобным копированием в один клик.
- **Params** — параметры из адресной строки (после знака `?`), аккуратно разложенные в таблицу и очищенные от непонятных `%20`.
- **Cookies** — отправленные и полученные куки, включая отметки их защищенности (`HttpOnly`, `Secure`, `SameSite`).
- **JSON / XML** — красиво отформатированный текст данных с подсветкой и поиском (`Ctrl+F` внутри редактора).
- **Image** — предпросмотр картинок, иконок и графики с указанием их размера и разрешения.
- **Raw** — исходный вид сообщения ровно так, как оно передавалось по сети.

### Специальные вкладки, когда нужно копнуть глубже:
- **Auth (Авторизация)** — сама находит токены доступа и логины/пароли в запросе, расшифровывает их и предупреждает о проблемах (например, если срок действия JWT-токена уже истек или пароль передается в открытом виде без HTTPS).
- **Caching (Кэширование)** — простыми словами показывает, разрешено ли браузеру сохранять этот ответ в кэш, свежий ли он и когда истечет срок хранения.
- **SSE (Потоковые ответы и нейросети)** — незаменима при работе с ChatGPT, Claude, Gemini и другими потоковыми сервисами: показывает приходящие кусочки по времени, а кнопка **«Собрать весь стрим LLM в один текст»** склеивает сотни мелких фрагментов в готовый читаемый ответ.
- **WS (WebSockets)** — показывает живую переписку в чатах, уведомлениях и играх: каждое сообщение со стрелочкой направления (от клиента `↑` или от сервера `↓`).
- **Multipart (Формы и файлы)** — раскладывает по полочкам отправленные веб-формы и показывает миниатюры прикрепленных картинок.
- **gRPC / Proto и Hex** — помогают прочитать бинарные данные и сообщения Protobuf даже без файлов схем.

> [!NOTE]
> Если ответ сервера весит очень много (больше 2 МБ — например, видео или крупный архив), FluxProxy бережет память компьютера и не загружает его целиком сразу. При открытии такого ответа в инспекторе просто нажмите кнопку подгрузки содержимого, или сохраните файл сразу на диск.

## 6. Фильтры: как убрать лишний шум и сберечь память

### Быстрый поиск и категории на верхней панели
- Введите часть адреса, домена, метода или кода ошибки в строку поиска (**`Ctrl+F`**). Кнопка **`.*`** рядом включает поиск по регулярным выражениям.
- Справа от строки поиска расположены кнопки быстрых категорий: **`All`** (все), **`JSON`**, **`SSE`**, **`Img`** (картинки), **`4xx/5xx`** (только ошибки), **`WS`**, **`Mock`** (подмененные) и **`Marked`** (отмеченные вами).
- Кнопка **`Tail`** управляет автопрокруткой: когда она включена, список сам прокручивается к самым свежим запросам; если вы листаете список вверх, автопрокрутка не мешает чтению.

### Расширенные фильтры (`Alt+4` или кнопка `Filter`)
Если нужно настроить отбор точнее, откройте панель фильтров:
1. **Готовые пресеты** — переключатели в один клик:
   - *«Только API бэкенда»* — убирает картинки, шрифты, стили и служебные запросы, оставляя чистые обращения за данными;
   - *«Скрыть аналитику и фоновый шум ОС»* — прячет системную телеметрию, проверки обновлений Windows/macOS и рекламные счетчики;
   - *«Медленные и тяжелые»* — находит запросы дольше 500 мс, ответы тяжелее 1 МБ и ошибки сервера;
   - Вы также можете сохранить свою комбинацию настроек как собственный пресет.
2. **Списки сайтов (Hosts List)** — вставьте список нужных доменов (по одному в строке, поддерживаются маски вроде `*.mycompany.ru`), выберите режим **Whitelist** (показывать *только* их) или **Blacklist** (скрыть их).
3. **Матрица условий (Filter Matrix)** — позволяет собрать любое правило из выпадающих списков, например: *«Показать запросы, где метод = POST и время ответа > 300 мс»*.
4. **Пороги шума (Thresholds)** — быстрые галочки для скрытия ответов `304 Not Modified`, проверочных `OPTIONS`-запросов, статики и туннелей `CONNECT`.

### Контроль памяти при долгой работе (`Keep` и `Drop Non-Matching`)
Если вы оставляете FluxProxy включенным на несколько часов:
- **Переключатель `Keep` на панели инструментов** задает, сколько последних запросов держать в списке (например, `500`, `1 000`, `10 000` или любое свое число через пункт *Custom…*). Более старые записи автоматически убираются из оперативной памяти.
- **Режим «Не сохранять лишнее» (`Drop Non-Matching`)** — включается в меню кнопки `Keep` или через **Tools → Session Retention Limit → Drop Non-Matching on Capture**. Когда эта галочка активна, все запросы, не подходящие под ваши текущие фильтры, **отбрасываются сразу на входе** и вообще не занимают память. В правой части нижней строки состояния вы всегда видите, сколько сессий сейчас в памяти и сколько фонового шума было отсеяно (`Dropped`).

## 7. Если перестали работать мессенджеры или банки (Избирательный HTTPS)

Некоторые приложения с повышенной защитой — например, Telegram, WhatsApp, банковские клиенты, платежные шлюзы, игры с античитом или системные службы Apple и Windows — жестко проверяют подлинность сервера и **отказываются работать**, если видят между собой и сервером любой отладочный прокси.

Во FluxProxy эта проблема решается двумя простыми способами:

### Способ 1 (Рекомендуемый): Расшифровывать только нужные вам сайты
Вместо того чтобы вмешиваться во весь интернет-трафик компьютера, скажите программе расшифровывать **только те сайты, которые вы сейчас тестируете**:
1. На верхней панели инструментов нажмите на переключатель режима HTTPS (или в меню **Rules → Selective MITM: Targeted Allowlist**).
2. Включите режим **Targeted Only** и добавьте домен вашего проекта (например, `*.my-app.dev`).
3. Либо просто кликните правой кнопкой мыши по нужному запросу в таблице и выберите **Always inspect (`ваш-домен`)**.

Теперь ваш рабочий сайт полностью виден во всех деталях, а все остальные приложения, мессенджеры и игры идут напрямую без единой ошибки!

### Способ 2: Добавить капризное приложение в список обхода
Если вам удобнее расшифровывать всё подряд, но конкретный сервис выдает ошибку соединения:
- Кликните правой кнопкой мыши по его строке в таблице и выберите **Always passthrough (`домен`)**.
- Или откройте **Rules → TLS Allowlist & Bypass Domains…** и в один клик подключите готовые наборы исключений для сервисов Apple/iCloud, обновлений Windows, мессенджеров и платежных систем.

## 8. Перехват на паузе и подмена ответов сервера

### Пауза и ручная правка на лету (Breakpoints)
Точки останова позволяют «поймать» запрос по дороге, спокойно изменить в нем любые данные и пустить дальше:

1. **Поймать запрос перед уходом на сервер:** нажмите **`F11`** (или кнопку паузы запроса на панели). Отправьте форму на сайте — всплывет окно перехвата. Поменяйте метод, заголовки или текст запроса и нажмите **Execute / Continue**.
2. **Поймать ответ сервера перед показом в браузере:** нажмите **`Alt+F11`**. Когда сервер ответит, вы сможете переписать текст ответа или одним кликом нажать кнопку ошибки (**`500`**, **`403`**, **`404`**, **`502`**), чтобы проверить, покажет ли ваш сайт понятное сообщение пользователю.
3. **Ловить не всё подряд, а только один адрес:** нажмите **`Ctrl+K`**, введите `bpu /api/orders` и нажмите `Enter` — на паузу будут вставать только запросы к `/api/orders`, не мешая загрузке остальной страницы. Аналогично команда `bpafter /api/orders` ловит только ответы.
4. Чтобы мгновенно отключить все паузы и отпустить задержанные запросы, нажмите **`Shift+F11`**.

### Автоматическая подмена ответов (AutoResponder, `Alt+3`)
Если нужно, чтобы определенный адрес **всегда** возвращал заготовленный вами ответ (например, сервер еще не написан разработчиками или нужно много раз воспроизвести редкую ситуацию):

1. Самый простой путь: кликните правой кнопкой мыши по похожему запросу в таблице и выберите **«Создать правило AutoResponder»**.
2. Откроется готовое правило, куда уже скопированы адрес и пример ответа.
3. Выберите, что должно происходить при совпадении адреса (*Rule Action*):
   - **Mock Local Response** — сразу вернуть ваш собственный статус, заголовки и JSON-ответ без обращения к реальному серверу;
   - **Forward & Override Status** — выполнить настоящий запрос, но заменить код ответа (например, на `429`);
   - **Inject Latency Only** — ничего не менять в данных, но искусственно задержать ответ на нужное число миллисекунд (поле *Latency*), чтобы проверить, как выглядят индикаторы загрузки при медленном интернете.
4. Нажмите **Apply Rule**. Включать и временно выключать весь автоответчик целиком можно одним переключателем в шапке раздела AutoResponder или в настройках (`Ctrl+,`).

### Автоматическая правка заголовков (без кэша, без ошибок CORS, смена устройства)
- Чтобы браузер всегда запрашивал свежие данные с сервера, а не брал из кэша, включите **Rules → Disable Caching (Strip ETag / IMS)** (или соответствующую кнопку на панели).
- В разделе **Rules → Filter Matrix & Header Mutations…** можно одной кнопкой включить автоматическое добавление заголовков **CORS** (для локальной разработки фронтенда) или притвориться мобильным браузером iPhone / Android с помощью готовых шаблонов **User-Agent**.

## 9. Отправка своих запросов, сравнение и декодер токенов

### Конструктор запросов (Request Composer, `Alt+2`)
Позволяет отправлять собственные запросы к API прямо из FluxProxy (как в Postman):
- Выберите метод (`GET`, `POST`, `PUT`, `DELETE` и др.), укажите адрес, заголовки и тело запроса и нажмите **Send**.
- **Удобный прием:** включите **View → Split Composer Pane**, чтобы открыть конструктор бок о бок со списком трафика, и **просто перетащите мышкой** любую строку из таблицы в поле конструктора — все заголовки и данные заполнятся сами!

### Сравнение двух запросов (Session Diff, `Ctrl+D`)
Представьте: вчера запрос возвращал `200 OK`, а сегодня такой же запрос выдает `400 Bad Request` или `403 Forbidden`. Вручную искать разницу среди десятков заголовков и полей JSON долго:
1. Зажмите `Ctrl`, кликните по двум строкам в таблице и нажмите **`Ctrl+D`** (или просто выберите одну строку и нажмите `Ctrl+D` — программа сама подберет для сравнения похожий запрос к тому же адресу с другим результатом!).
2. Откроется наглядное сравнение, где все отличия подсвечены цветом отдельно по заголовкам, кукам/токенам, телу запроса и ответу.
3. Включите галочки **Sort Keys & Headers** (отсортировать поля по алфавиту) и **Ignore Volatile Headers** (скрыть меняющиеся каждую секунду даты и технические ID), чтобы увидеть только реальную суть отличий.

### Декодер текста и токенов (Text Wizard, `Ctrl+E`)
Встроенный помощник для расшифровки и преобразования непонятных строк без перехода на сторонние сайты (куда небезопасно вставлять рабочие токены и пароли):
- **JWT Inspect** — вставьте токен авторизации (`eyJ...`), чтобы увидеть зашитые в него права пользователя и точный таймер, сколько минут осталось до истечения токена. *(Совет: токен можно вставить даже сразу в командную строку `Ctrl+K`!)*
- **Base64** и **URL Codec** — кодирование и раскодирование строк и ссылок в обе стороны.
- **Compression** — сжатие и распаковка текста в форматах Gzip, Brotli и Deflate с подсчетом экономии размера.
- **Hex** — перевод текста в байтовый вид и обратно.
- **Timestamp** — мгновенный перевод чисел времени Unix (вроде `1731150000`) в понятную дату и время в вашем часовом поясе.

## 10. Проверка трафика со смартфона или планшета (iOS и Android)

Чтобы посмотреть, какие запросы отправляет браузер или приложение на вашем телефоне, убедитесь, что **телефон и компьютер подключены к одной и той же Wi-Fi сети**, и выполните 4 простых шага:

1. На компьютере во FluxProxy нажмите **`Ctrl+Shift+M`** (или выберите **Tools → Connect Mobile Device…**).
2. В открывшемся окне включите прием внешних подключений (**`0.0.0.0`**), если программа предложит это сделать. На экране появятся адрес вашего компьютера в сети (например, `192.168.1.45`), порт (`8888`) и большой **QR-код**.
3. На смартфоне откройте настройки вашей текущей Wi-Fi сети, найдите пункт **Прокси (HTTP-прокси) → Вручную** и впишите указанные на экране **Сервер (IP)** и **Порт**.
4. Установите сертификат на телефон:
   - Наведите камеру телефона на **QR-код** на экране компьютера (или откройте в браузере телефона короткий адрес `http://flux.proxy`).
   - **На iPhone / iPad:** скачайте профиль → откройте *Настройки → Профиль загружен → Установить*, а затем обязательно включите доверие в *Настройки → Основные → Об этом устройстве → Доверие сертификатам*.
   - **На Android:** скачайте сертификат `.crt` и установите его через *Настройки → Безопасность → Шифрование и учетные данные → Установка с накопителя → Сертификат CA*. *(Примечание: современные приложения на Android по умолчанию доверяют системным сертификатам только в тестовых/отладочных сборках — готовый кусочек настроек для разработчика также можно скопировать прямо из окна мастера).*

Готово! Все запросы с телефона появятся в таблице с заметным зеленым значком смартфона 📱. Нажмите на этот значок в любой строке, чтобы скрыть трафик компьютера и видеть только свой телефон.

> [!IMPORTANT]
> **Не забудьте после завершения проверки** вернуть настройку прокси в свойствах Wi-Fi на телефоне обратно в положение **«Выкл.» (Авто)** — иначе при выключенном на компьютере FluxProxy телефон не сможет выходить в интернет через эту Wi-Fi сеть.

## 11. Сохранение файлов, обмен с коллегами и настройки программы

### Как сохранить перехваченный трафик и отправить коллеге
- **Сохранить все сессии (`Ctrl+S` или File → Save All Sessions As…):** выберите формат:
  - **`.har` (HTTP Archive)** — универсальный формат, который открывается не только во FluxProxy, но и в любом браузере Chrome / Edge / Firefox (вкладка *Network → Import HAR*), а также в Postman и Charles;
  - **`.saz`** — родной архив классического Fiddler Classic;
  - **`.json`** — полный внутренний формат FluxProxy.
- **Сохранить только нужные запросы:** выделите одну или несколько строк в таблице → кликните правой кнопкой мыши → **Save Selected as HAR (`.har`)** или **Save Selected as Fiddler SAZ (`.saz`)** (либо через меню *File → Save Selected Sessions…*).
- **Открыть чужой архив (`Ctrl+O` или File → Open / Import Archive…):** выберите файл `.har`, `.saz` или `.json` на диске — либо **просто перетащите этот файл мышкой прямо в окно FluxProxy**!
- **Скачать картинку, файл или ответ отдельно:** кликните правой кнопкой мыши по строке в таблице и выберите **Save Response Body As…** (или **Save Request Body As…**) — программа сама предложит подходящее расширение файла (`.json`, `.png`, `.html` и др.).
- **Локальная база SQLite:** если вы хотите быстро делать снимки текущего рабочего сеанса внутри программы без выбора файлов на диске, используйте пункты **File → Save Archive to SQLite** и **Restore Archive from SQLite**.

### Настройки программы и перенос профиля (`Ctrl+,`)
Нажмите **`Ctrl+,`** (или откройте **File → Preferences…**), чтобы открыть единый центр настроек:
- Здесь собраны в одном месте выбор темы, компактного режима, видимых колонок, **смена порта прокси** (если порт `8888` занят другой программой), лимиты памяти, фильтры и правила подмены.
- Во вкладке **Backup & Export** (или через меню **File → Export / Import Settings Profile**) вы можете выгрузить абсолютно все свои настройки, сохраненные фильтры, списки доменов и правила автоответчика в один аккуратный файл `fluxproxy-settings-v1.json`. При загрузке файла на другом компьютере программа заранее покажет наглядную сводку того, какие настройки будут применены.
- Там же доступна кнопка **Reset to Defaults**, если вы захотите вернуть программу к чистому заводскому состоянию.

### Подключение программ из командной строки (терминала)
Консольные утилиты (`curl`, `python`, `node`, `npm`, `git`) обычно не смотрят на системный прокси Windows/macOS. Чтобы увидеть их запросы во FluxProxy, выберите в меню **Help → Copy CLI HTTP_PROXY Snippet** и вставьте скопированную команду в окно терминала перед запуском вашей программы.

## 12. Частые вопросы и решение проблем

**Браузер пишет «Подключение не защищено» (`NET::ERR_CERT_AUTHORITY_INVALID`) на всех сайтах**
> Корневой сертификат еще не установлен. Откройте **Tools → HTTPS Root CA Certificate…** и нажмите **Trust Root CA in OS Store**, после чего перезапустите вкладку сайта. Если ошибка только в браузере **Firefox** — импортируйте файл сертификата в собственных настройках Firefox (см. [Шаг 2 быстрого старта](#шаг-2-установите-сертификат-для-защищенных-сайтов-https)).

**Захват включен, но в таблице не появляется ни одного запроса**
> Проверьте три вещи:
> 1. Включен ли системный прокси — индикатор **`SysProxy: ON`** в правой верхней или нижней части окна должен гореть зеленым.
> 2. Не остался ли текст в строке быстрого поиска (`Ctrl+F`) или активный жесткий фильтр — нажмите кнопку сброса фильтров, если счетчик показывает, что сессии скрыты.
> 3. Если вы проверяете локальный сайт на `localhost` / `127.0.0.1`, некоторые браузеры по умолчанию не пускают локальные адреса через системный прокси — попробуйте обратиться по локальному имени или отправить запрос через встроенный **Request Composer (`Alt+2`)**.

**При включенном FluxProxy не подключается мессенджер, банковский клиент, игра или пакетный менеджер**
> Это срабатывает встроенная защита приложения от проксирования (Certificate Pinning). Кликните правой кнопкой мыши по строке этого приложения в таблице и выберите **Always passthrough**, либо переключите FluxProxy в режим избирательной расшифровки **Targeted Only** (см. [Раздел 7](#7-если-перестали-работать-мессенджеры-или-банки-избирательный-https)).

**После сбоя питания или принудительного закрытия перестал открываться интернет в браузере или на телефоне**
> - **На компьютере:** просто запустите и штатно закройте FluxProxy (или нажмите `F12`) — программа автоматически очистит настройки системного прокси.
> - **На смартфоне:** зайдите в настройки Wi-Fi на телефоне и переключите пункт *HTTP-прокси* из режима *«Вручную»* обратно в *«Выкл.»*.

## 13. Шпаргалка по горячим клавишам

Открыть эту подсказку прямо внутри программы можно в любой момент клавишей **`?`**. Также почти любое действие можно быстро найти по названию через командную строку **`Ctrl+K`** (`Cmd+K` на macOS).

### Главные клавиши управления

| Клавиши | Что делает |
| :--- | :--- |
| **`F12`** | Включить или поставить на паузу перехват трафика |
| **`Ctrl+K`** / `Cmd+K` | Открыть командную строку быстрого вызова любых действий |
| **`Ctrl+,`** / `Cmd+,` | Открыть настройки программы и профилей (**Preferences**) |
| **`Ctrl+F`** / `Cmd+F` | Перейти в строку быстрого поиска по списку запросов |
| **`Ctrl+S`** / `Cmd+S` | Сохранить все запросы в файл (`.har`, `.saz`, `.json`) |
| **`Ctrl+O`** / `Cmd+O` | Открыть сохраненный архив запросов (`.har`, `.saz`, `.json`) |
| **`Ctrl+Shift+M`** | Открыть окно подключения смартфона по Wi-Fi с QR-кодом |
| **`Ctrl+E`** / `Cmd+E` | Открыть декодер текста и JWT-токенов (**Text Wizard**) |
| **`?`** | Показать окно со списком всех горячих клавиш |

### Работа со списком запросов

| Клавиши | Что делает |
| :--- | :--- |
| **`↑` / `↓`**, **`Home` / `End`** | Перемещение по списку запросов |
| **`Shift + ↑ / ↓`** или **`Ctrl + Клик`** | Выделить сразу несколько запросов |
| **`Enter`** или **`Пробел`** | Открыть инспектор деталей / переключить фокус обратно в таблицу |
| **`R`** или **`Ctrl+R`** | Повторить выбранный запрос заново (**Replay**) |
| **`Ctrl+D`** / `Cmd+D` | Сравнить два запроса бок о бок (**Session Diff**) |
| **`M`** / **`U`** | Добавить цветную метку и комментарий (`M`) / убрать метку (`U`) |
| **`Ctrl+C`** / `Cmd+C` | Скопировать ссылку выбранного запроса |
| **`Delete`** / **`Backspace`** | Удалить выбранные запросы из списка |
| **`Ctrl+X`** / `Cmd+X` | Полностью очистить весь список запросов |

### Паузы перехвата и переключение разделов

| Клавиши | Что делает |
| :--- | :--- |
| **`F11`** | Ставить на паузу запросы перед отправкой на сервер |
| **`Alt+F11`** | Ставить на паузу ответы сервера перед показом в браузере |
| **`Shift+F11`** | Выключить все паузы и отпустить задержанные запросы |
| **`Ctrl+B`** / `Cmd+B` | Скрыть или показать левую боковую панель |
| **`Alt+1`**, **`Alt+2`**, **`Alt+3`**, **`Alt+4`** | Разделы: *Трафик* (`1`), *Конструктор* (`2`), *Автоответчик* (`3`), *Фильтры* (`4`) |
